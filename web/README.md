# CertifyApp Web — Biznes portalı

Vite + React + Tailwind 3.4. Təşkilatlar üçün: tədbirlər, sertifikat buraxılışı, çap, istifadəçi/biznes idarəetməsi.

## İşə salma

```bash
npm install
npm run dev
```

Backend gateway **8090** işləməlidir (Vite proxy).

## Build

```bash
npm run build
npm run preview
```

`dist/` statik host üçün hazırdır.

## Qeydiyyat

Web qeydiyyatı avtomatik **BUSINESS** rolu göndərir. İstifadəçilər mobil tətbiqdən **USER** ilə qeydiyyatdan keçir.
